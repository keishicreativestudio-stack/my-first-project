## 撮影するもの

Day1 と同じやり方で、**画面録画を1本**撮ります（左に Claude Code、右にブラウザ）。
送ってもらえれば、作っている場面・入力する場面・円グラフの場面を切り出します。

| 録画の中で撮る場面 | ポイント |
|---|---|
| ① Claude Code に指示を貼って、完成するまで | そのままでOK（8倍速にします） |
| ② 完成したアプリで、金額を3〜4件入れる | ゆっくり操作する。カテゴリはばらけさせる |
| ③ 円グラフと今月の合計が出ているところ | 3秒ほど止めておく |

ファイル名は `1005_screen.mov` にして `tiktok-studio/scripts/rec/` へ（送ってもらえれば私が置きます）。

### Claude Code への指示（そのまま貼る）

```
スマホで使える家計簿アプリを、HTMLファイル1つで作って。
・金額とカテゴリ（食費・日用品・交通・その他）を入れるだけ
・今月の合計と、カテゴリ別の円グラフを表示
・閉じてもデータが消えないようにして
```

### 入力する金額の例（実際の家計ではなく、この例を使うのがおすすめ）

| カテゴリ | 金額 |
|---|---|
| 食費 | 1,280 |
| 日用品 | 650 |
| 交通 | 420 |
| 食費 | 2,300 |

### 撮影のコツ
- ブラウザはスマホの大きさで表示する（Day1 と同じ）。縦長の画面になり、動画で大きく映る
- かかった時間を測っておく（Claude Code の画面に出る時間でOK）
- 通知はオフ。ファイルの保存場所やユーザー名が映り込まないようにする
