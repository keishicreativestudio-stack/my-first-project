# ChatGPT 用プロンプト集

`【 】` の部分を書き換えて、そのまま ChatGPT に貼り付けて使います。

---

## 1. 台本JSONを作る（毎日使う）

```
あなたはTikTokのショート動画の構成作家です。
AI活用ジャンルで、顔出し・声出しなしのテロップ動画を作ります。
次のネタで、15〜25秒の動画の台本を JSON で書いてください。

ネタ：【ideas_50.md のタイトル・冒頭テロップ・流れを貼る】
アカウント名：【@your_account】
シリーズ名：【なければ空欄】
テーマ：【dark / light / pop / green のどれか】

ルール：
- 形式は下の例と同じ JSON だけを出力する（説明文は不要）
- 1つ目のシーンは style を "hook" にし、1.5秒で読める強い一言にする
- 最後のシーンは style を "cta" にし、コメントかフォローか保存を促す
- テロップは1行8〜10文字で、\n で改行する
- 一番伝えたい言葉を1シーンに1か所だけ **強調** で囲む
- プロンプトを見せるシーンは "label" と "code" を使い、"text" は空にする
- 画面録画を入れる場所は "clip": "rec.mp4" と書く
- シーン数は5〜7個
- "caption" に TikTok の説明文を書く（2〜3行。1行目に動画の結論、検索されやすい言葉を入れ、最後はコメントしたくなる問いかけで終える。誇張しない）
- "hashtags" は5〜6個。大きいタグ（#ChatGPT など）と内容に合う小さいタグを混ぜ、最後は必ず #AIチャレンジ365

例：
{
  "handle": "@your_account",
  "series": "AIチャレンジ Day◯",
  "theme": "dark",
  "caption": "コードは1行も書かずに、AIにゲームを作らせてみた。\n次は何を作らせる？コメントでリクエストください！",
  "hashtags": ["#ClaudeCode", "#AIでゲーム作り", "#個人開発", "#生成AI", "#AIチャレンジ365"],
  "scenes": [
    {"style": "hook", "text": "AIに\n「**ゲーム作って**」\nって言っただけの結果…"},
    {"label": "AIへの指示はこれだけ", "code": "落ちものパズルゲームを作って。", "text": ""},
    {"text": "作っている様子（**4倍速**）", "clip": "rec.mp4", "clip_speed": 4},
    {"style": "cta", "text": "次は何を作らせる？\n**コメントで募集中**"}
  ]
}
```

## 2. 冒頭のつかみ（フック）を10案出す

```
TikTokのショート動画の最初の1秒に出すテロップを10案出してください。

動画の内容：【内容】
見てほしい人：【例：仕事でAIを使いたい20〜30代】

条件：
- 15文字以内
- 「続きが気になる」「自分のことだ」と思わせる
- 誇張や嘘はしない
- 型を混ぜる（疑問／意外な結果／損をしている／数字）

最後に、一番強いと思う3案と、その理由を書いてください。
```

## 3. キャプションとハッシュタグ

```
次のTikTok動画の投稿キャプションを3案作ってください。

動画の内容：【内容】

条件：
- 1〜2行で、コメントしたくなる問いかけで終わる
- ハッシュタグは4〜5個。大きいタグ（#AI #ChatGPT）と小さいタグ（#AI活用術 など）を混ぜる
```

---

## 4. 伸びた動画の型を分析する（週1回）

```
私のTikTok動画の今週の数字です。伸びた理由と伸びなかった理由を分析して、
来週の7本のネタを「伸びた型」に寄せて提案してください。

| タイトル | 型 | 再生数 | 完了率 | 平均視聴秒 | 新規フォロー |
|---|---|---|---|---|---|
【content/ideas_50.csv から今週の行を貼る】

出力：
1. 伸びた動画に共通すること（3つ）
2. 伸びなかった動画に共通すること（3つ）
3. 来週の7本（タイトル・冒頭テロップ・流れ）
```

## 5. Claude Code への指示（「AIに作らせてみた」用）

撮影するときに Claude Code に渡す指示の例です。短いほど動画映えします。

```
スマホでも遊べる落ちものパズルゲームを、HTMLファイル1つで作って。
スコアとゲームオーバー画面も付けて。
```

```
今日の日付から、指定した誕生日までの日数を大きく表示するページを作って。
お祝いの日は紙吹雪が降るようにして。
```

```
4択の英単語クイズアプリを作って。
間違えた単語だけもう一度出る「復習モード」も付けて。
```

撮影のコツ:
- 画面の文字を大きく（ターミナルの文字サイズを 20pt 以上）
- 作っている部分は 4〜8倍速にして、完成品を遊ぶ場面に時間を使う
- 通知はオフにし、個人情報やAPIキーが映らないようにする
