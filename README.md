# 間取りメーカー

部屋・建具・家具の図形を組み合わせて間取り図を作るブラウザアプリです。
`index.html` をブラウザで開くだけで動きます（インストール不要）。

## できること

- パレットから部屋（洋室・LDK・和室・浴室など）、壁・ドア・引き戸・窓・階段、キッチン・浴槽・ベッドなどを配置
- ドラッグで移動、四隅・各辺のハンドルで伸縮
- **辺に吸着**：図形どうしの辺・中心が近づくと赤いガイドが出て、ぴったり合わさる
- グリッド吸着（910 / 455 / 91 / 10mm）
- 部屋ごとの帖数・㎡、延床面積（㎡・帖・坪、重なりは二重計上しない）を自動計算
- 90°回転（R）、左右反転（F）、複製（Ctrl+D）、削除（Del）、元に戻す／やり直し
- ブラウザに自動保存、JSONで保存・読込、PNG画像で書き出し
- スマホ対応（ピンチで拡大縮小）

面積の帖数は 1帖 = 1.62㎡ で換算しています。
