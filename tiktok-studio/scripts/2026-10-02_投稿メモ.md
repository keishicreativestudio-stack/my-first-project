# 10/2（Day2）投稿メモ｜冷蔵庫の写真だけで献立を作らせる

台本：`2026-10-02.json`
型：B（ChatGPT活用術）
投稿時間の目安：朝7時台か、夕方17〜18時台（夕飯の献立を考える時間）

## 用意するもの（2つ）

撮ったものは `tiktok-studio/scripts/rec/` に、次の名前で保存します。

| ファイル名 | 内容 | ポイント |
|---|---|---|
| `1002_fridge.jpg` | 冷蔵庫の中の写真 | 扉を開けて正面から明るく撮る。食材が5〜10種類見えるとよい |
| `1002_chatgpt.mp4` | スマホの画面録画 | ChatGPTアプリで写真を送ってから、献立と買い物リストが全部出るまで |

録画は**スマホで撮るのがおすすめ**です。縦長なので、動画の画面にそのまま大きく入ります。
iPhone はコントロールセンターの「画面収録」、Android はクイック設定の「スクリーンレコード」で撮れます。

### ChatGPT に送る文（写真と一緒に送る）

```
この冷蔵庫の中身で、3日分の夕飯の献立を考えて。
・2人分、1食30分以内
・今ある食材をできるだけ使い切る
・足りない食材は買い物リストにまとめて
```

### 撮影のコツ
- 送信する前から録画を始め、答えが出たら**ゆっくりスクロール**する（速いと読めない）
- 冷蔵庫の写真に、郵便物・薬・子どもの名前入りの物など個人情報が写らないようにする
- 通知はオフにする（おやすみモードにすると確実）
- AIが食材を読み間違えることがあります。間違いが目立つ場合は撮り直すか、「一部読み間違いあり」とテロップで正直に出すと、かえってコメントが付きやすくなります

## 動画を作る

録画を送ってもらえれば、Day1と同じように、献立が出る場面と買い物リストの場面を切り出して仕上げます。
自分で作る場合：

```bash
cd tiktok-studio
python3 make_video.py scripts/2026-10-02.json
```

買い物リストが出る秒数に合わせて、台本の5つ目のシーンの `clip_start` を変えてください。
