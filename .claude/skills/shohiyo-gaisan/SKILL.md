# 販売図面 → 資金計算書（諸費用概算）

生成スクリプト: `shohiyo/make_estimate.py`（仲介手数料は `shohiyo/reds_fee.py`＝REDS calc10_2 ロジック）

## 手順

1. **図面を読む**（PDF は pdf スキル、画像はそのまま Read）。次を拾う:

   | JSON キー | 図面での表記 | 備考 |
   |---|---|---|
   | `name` | 物件名・マンション名・号棟 | |
   | `address` | 所在地・住居表示 | |
   | `type` | 種別 | `新築戸建` / `中古戸建` / `新築マンション` / `中古マンション` / `土地` のどれか。「新築」「未入居」「建築中」→新築、築年月があり居住歴あり→中古 |
   | `price` | 価格 | **円**で。税込価格（新築は税込表示が普通） |
   | `deal` | 取引態様 | `仲介`（「仲介」「媒介」「専任」「専属」の記載）/ `売主` / `代理` |
   | `fee_3pct` | 「手数料3%」「仲介手数料3%」等の記載 | あれば `true`（売主側が手数料を負担＝お客様は無料） |
   | `built_year` | 築年月の西暦年 | 1981年以前なら旧耐震注記が自動で付く |
   | `management_fee` / `repair_reserve` / `other_fee` | 管理費・修繕積立金・その他費用（自治会費等）の月額 | マンションのみ |
   | `initial_repair_fund` | 修繕積立基金 | 新築マンションで記載があれば |
   | `floor_area` | 専有面積（壁芯）／建物面積 | ㎡の数値 |
   | `structure` | 構造 | 「鉄筋コンクリート造」「木造」など図面の表記のまま |
   | `assessed_land` / `assessed_building` | 固定資産税評価額 | 図面や資料に記載があるときだけ（円） |

   日本語フォントのPDFで pdftotext が文字化け・空になるときは `apt-get install -y poppler-data` を入れてから再実行する。
   価格が画像で埋め込まれていて pdftotext で取れないことがある。その場合はページを画像化（pdftoppm）して拡大して読む。

   読めなかった項目は推測で埋めず、省略する（既定値が入る）。価格・種別・取引態様が読めない場合はユーザーに確認する。

   **仲介手数料の判定（`fee_plan` は通常 JSON に書かない＝自動判定）**
   - 「売主」「代理」、または「手数料3%」等の記載 → **無料**（`deal` / `fee_3pct` で自動）
   - 「仲介」「媒介」「専任」「専属」 → **割引**（REDS calc10_2 で計算）
   - 両方ある場合（例: 媒介＋手数料3%）は無料

2. **ユーザー指定があれば反映**: `fee_plan`（`割引` / `無料` / `半額` を明示指定）、
   `loan`（`amount` 融資額・既定は物件価格の全額、`rate` 金利%・既定1.195、`years` 既定35、`bonus` ボーナス加算額）、
   `overrides`（`登記費用` などを金額で上書き）。担当は「柴田」固定（既定値）。

3. **生成**:
   ```bash
   python3 shohiyo/make_estimate.py 物件.json 出力.xlsx
   ```
   計算結果は formulas パッケージでファイルに埋め込まれる（`pip install formulas`。LibreOffice は不要）。
   openpyxl の data_only で主要セル（仲介手数料・小計・総額差額・月々返済）を読み、None やエラーがないか確認する。

4. **ユーザーに送る**（SendUserFile）。返信には、読み取った物件情報・REDS仲介手数料と他社との差額・月々返済額・
   自動で置いた概算（登記・火災保険・固都税）を短く添える。図面と食い違いがないか確認を促す。

## 自動で決まる項目

- 契約書印紙代: 売買価格から（軽減税率、2027年3月31日まで）
- 仲介手数料: 上の判定どおり（無料／割引）。他社側は常に法定上限（税込）
- 事務代行手数料: REDS 0円 / 他社 55,000円
- 融資事務手数料: 融資額×2.2%、金消契約印紙: 融資額から
- 表示登記（新築戸建のみ）15万円、管理費等清算金（マンション）= 月額×2ヶ月
- 登記費用: 固定資産税評価額から登録免許税を計算し、合計を10万円単位で繰り上げ。仲介手数料が無料なら＋10万円、他社側も同額（Excel下部に内訳。評価額が無ければ推定値＝要差し替えと伝える）
- 火災保険: 構造・面積・都道府県から5年一括・地震保険込の相場（10万円単位で繰り上げ）
- 管理費等清算金: 月額×2ヶ月を百の位で繰り上げ
- 固都税清算は目安額
- 帳票に「様」欄・種別欄は出さない。文字は黒（仲介手数料・事務代行・小計・差額・自己資金のみ赤）
- レイアウトは元の資金計算書（マンション割引シート）と同じ配置・罫線・余白。登記費用の内訳は印刷範囲外

## 印刷イメージの確認（任意）
LibreOffice Calc があれば PDF にして見た目を確認できる（無ければ `apt-get install -y libreoffice-calc`）:
`soffice --headless --convert-to pdf 出力.xlsx` → `pdftoppm -r 100 -png 出力.pdf 画像`
