# Instagram ストーリーズ

リールを投稿した1〜2時間後に、ストーリーズに載せる。
**1枚目** = リールの動画 + テキスト + リンクスタンプ(ショップへ)
**2枚目** = スタンプ画像1枚 + アンケートなどの参加スタンプ(反応が増えると、次のストーリーズも見られやすくなる)

リンクスタンプは「スタンプ」→「リンク」で、スタンプショップのURLを貼る。「スタンプのテキストをカスタマイズ」で表示文字を変えられる。

# Threads

- Threadsは**会話っぽい、ゆるい独り言**のほうが反応されやすいので、宣伝感を弱めて「作った人の気持ち」を出す
- 動画を添付して投稿する(1投稿500文字まで)
- **トピックタグは1投稿に1つだけ**付けられるので、`LINEスタンプ` を付ける(投稿画面で「#」から選ぶ)
- 買う場所は**自分の投稿につなげて2つ目の投稿**に書く(1つ目は動画と会話だけにする)
- 時間は TikTok と同じ 19〜21時(土曜は12時ごろ)
