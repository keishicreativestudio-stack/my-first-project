# 10/1（Day1）投稿メモ｜AIに落ちものパズルゲームを作らせてみた

台本：`2026-10-01.json`
投稿時間の目安：20〜22時台

## 撮影するもの（2本）

画面録画は `tiktok-studio/scripts/rec/` に、次の名前で保存します。

| ファイル名 | 撮る内容 | 長さの目安 |
|---|---|---|
| `1001_build.mp4` | Claude Code に下の指示を貼って、コードを書き終わるまで | そのままでOK（8倍速にして約5秒使います） |
| `1001_play.mp4` | 完成したゲームをブラウザで開いて遊ぶ様子 | 10〜20秒（最初の6秒を使います） |

録画がまだ無くても、動画は「ここに画面録画」という仮の枠で作れます。仕上がりの確認に使ってください。

### Claude Code への指示（そのまま貼る）

```
スマホでも遊べる落ちものパズルゲームを、HTMLファイル1つで作って。
スコアとゲームオーバー画面も付けて。
```

### 撮影のコツ
- ターミナルとブラウザの文字は大きめ（20pt 以上）
- 通知はオフにする。ファイルのパスやユーザー名など、個人情報が映らないようにする
- ゲームは、ブロックが消える瞬間とゲームオーバーまで撮る
- かかった時間を測っておき、台本の「たったの◯分」の ◯ に入れる

## 動画を作る

```bash
cd tiktok-studio
python3 make_video.py scripts/2026-10-01.json
```

→ `out/2026-10-01.mp4` を CapCut に入れ、BGM（TikTok内の流行り音源がおすすめ）を付けます。
読み上げ音声を付ける場合は、`out/2026-10-01.srt` を読み込ませてテキスト読み上げを使います。
