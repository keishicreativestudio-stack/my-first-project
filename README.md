# ChatGPTプロンプト活用ショート動画（AIチャレンジ365 Day4）

TikTok / YouTube Shorts向けの縦型ショート動画を、HTML / CSS / JavaScriptのみ（外部ライブラリ・外部素材なし）で制作したものです。ブラウザで `index.html` を開くだけで、最初から最後まで自動再生され、終了後はシームレスにループします。

## 動画の目的

「ChatGPTに普通に質問するのをやめて、回答前に不足情報を質問させる一文を足す」というテクニックを、ChatGPT初心者やAIを仕事・副業に活かしたい層に向けて分かりやすく紹介する動画です。視聴者が動画を保存し、その場でChatGPTに試したくなることをゴールにしています。

## 再生方法

1. このフォルダ（`index.html` と同じ階層）をローカルサーバーで開く、またはブラウザで `index.html` を直接開きます。
   - 例: `python3 -m http.server 8000` を実行し、`http://localhost:8000/index.html` にアクセス。
   - ローカルファイルを直接ダブルクリックで開いても動作します。
2. ページを開くと同時に自動再生が始まります（クリックや操作は不要）。
3. 動画は約29.5秒でループします（CTA表示後、シームレスに冒頭へ戻ります）。
4. `?debug=1` をURLに付けて開くと、左上に経過時間と現在のシーン名を表示するデバッグ表示が出ます（本番の見た目には影響しません）。
5. 再生中に画面をクリックする、または `R` キーを押すと、いつでも最初から再生し直せます（確認用）。

## 動画仕様

- 解像度: 1080 × 1920（9:16 縦型）
- 長さ: 約29.5秒（ループ再生）
- 使用技術: HTML / CSS / JavaScriptのみ（外部フォント・画像・ライブラリ不使用、システムフォントとインラインSVGのみ使用）
- セーフエリア: 上下左右に余白を確保し、TikTok / Shorts等のUI（いいねボタン、キャプション等）と重ならない設計

## 構成（タイムライン）

| 時間 | シーン | 内容 |
|---|---|---|
| 0.0〜2.0s | フック | 「ChatGPT、普通に質問するのやめて。」を強いパンチインで表示 |
| 2.0〜5.0s | 一文の提示 | 「最後に／この一文を足してみて。」、「この一文」をグラデーションでハイライト |
| 5.0〜10.0s | BEFORE | ChatGPT風チャットで「副業のアイデアを考えて」→ ありきたりな回答（ぼかし表現）→「なんか普通…😐」 |
| 10.0〜15.0s | AFTER | 同じ質問に「回答する前に、不足している情報があれば質問してください。」を追加し、強調表示 |
| 15.0〜21.0s | 3つの質問 | ChatGPTが「使える時間は？」「初期費用は？」「得意なことは？」をテンポよく順番に質問 |
| 21.0〜25.0s | 変化の可視化 | ありきたり（グレー）→ あなた専用（カラー）の比較 ＋「自分に合った回答に変わる。」 |
| 25.0〜29.5s | CTA | 「この一文、保存して使ってみて。」＋「AIチャレンジ365」 |

全シーン共通で、ごく微細なズーム（Ken Burns風の動き）を常時加え、静止画感を減らしています。

## 録画方法（動画ファイル化する場合）

ブラウザ上でアニメーションとして完結しているため、実際に `.mp4` 等のファイルに書き出す場合は画面録画を行います。

### 方法A: OS標準の画面録画

1. ブラウザを1080×1920相当の比率で表示（ウィンドウを縦長にする、またはブラウザの端末エミュレーション機能でカスタムサイズ 1080×1920 を指定）。
2. macOSは `Cmd+Shift+5`、Windowsは `Win+Alt+R`、その他OSは標準の画面収録機能で `index.html` の表示領域を録画開始。
3. ページをリロードして再生開始と同時に録画、CTA表示が終わるところ（約29.5秒後）で録画停止。

### 方法B: Playwright等での自動録画（開発者向け）

Chromiumの `recordVideo` オプション付きでページを開き、`1080x1920` のビューポートで29.5秒待機してから閉じることで、ノーカットの `.webm` を自動生成できます。書き出し後、必要に応じて`ffmpeg`で `.mp4` に変換してください。

```bash
ffmpeg -i output.webm -c:v libx264 -pix_fmt yuv420p output.mp4
```
