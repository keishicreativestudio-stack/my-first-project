# LINEスタンプ広告の投稿セットを作る

ユーザーがスタンプ画像のzip(または画像)を送ってきたら、この手順で**動画4本+投稿文一式+予約表+zip**を作る。
過去の完成例: `モフ雲/`、`限界会社員アザラシ/`、`社会人カワウソ/` と、その台本 `scripts/sticker/{kumo,seal,otter}/`。

ユーザーへの返事は日本語で、専門用語を避けて書く。

## 1. 取り込み(道具)
```bash
python -m shorts.sticker_kit prepare <zipのパス> <英数字の名前>
```
- 画像は `assets/stickers/<名前>/01.png…` に入る。メイン画像とタブ画像は `_extra/` に分けられる。同じセリフの白背景版などは自動で除外される(除外したものは画面に出るので、ユーザーに伝える)。
- `output/<名前>_sheet.png` を Read で開いて、**全スタンプのセリフと表情を読む**。
- **正式なスタンプ名はzipのファイル名と同じ**(ユーザーのルール)。
  - `prepare` がzipの中のフォルダ名やzipのファイル名から読み取り、`assets/stickers/<名前>_extra/info.yaml` に保存する。
  - 「〇〇_LINEスタンプ_16個」のような名前なら、名前と個数を分けて読む。
  - この名前を台本の `title`、`package` のフォルダ名、投稿文のスタンプ名にそのまま使う。
- 次の場合は正式名を推測で作らず、ユーザーに聞く。
  - 画面に「スタンプ名: ???」と出た(アップロードで日本語が「_」に置き換わると読めない)
  - 「ローマ字なので確認が必要」と出た
- 次回から確実に読めるよう、ユーザーには「**正式名のフォルダにスタンプ画像を入れてから、そのフォルダをzipにする**」と伝える(zipの中のフォルダ名は日本語のまま届く)。

## 2. 分析(ここは自分で考える)
次の5つを書き出して、ユーザーに短く伝える。
- キャラ(見た目・雰囲気)
- セリフの傾向(あいさつ/敬語/本音/天気など)
- 狙う人(年代・立場・悩み)
- **一番の武器**(共感ポイント、ギャップ、並べるとストーリーになるか)
- 既存のスタンプ(モフ雲・アザラシ・カワウソ)とどう差をつけるか

## 3. 4本の構成を決める
**スタンプの内容を生かす**のが最優先。型は既存の3つから選んで組み合わせる。
- `chat`(トーク型):あるある会話にスタンプで返す → 最後は「どこの？」→ 検索ワード。ほぼ毎回入れる
- `tempo`:1秒ずつテンポよく見せる。セリフに合わせて形を変える
  - 時系列に並ぶ → 「1日型」
  - 対になるセリフ → 「建前と本音」「返信のウラ側」
  - 普通と本音の2種類がある → 「ギャップ型」
  - テーマがある → 「天気予報型」など
- `quiz`(クイズ・診断型):4択を番号でコメントしてもらう。短くてループ向け。段階になる4つ(限界レベルなど)だとなお良い

冒頭の一言(hook)は、最初の2秒で止まってもらう言葉にする(名指し「○○な人」、共感、意外性)。

## 4. 台本4本を書く
- 型: `docs/sticker_script_template.yaml`。置き場所は `scripts/sticker/<名前>/01_xxx.yaml`〜`04_xxx.yaml`(**ファイル名の順が投稿順**。わかりやすい型→コメント狙いのクイズを最後に)
- `theme` はキャラの色に合わせる。LINEの緑や青灰色のトーク画面にはしない(LINEのガイドライン)
- `title` は info.yaml の正式名(読めなかったときだけ仮の名前にして `(仮)` と書き、最後にユーザーに聞く)。`count` も info.yaml の個数にする
- **検索ワード**は「スタンプ名の中で珍しい言葉」。ユーザーに LINE のスタンプショップで検索してもらい、上位に出るものに決める
- `captions` に全SNS分を書く(TikTok本文・固定コメント、Instagram、ストーリーズ、YouTubeタイトル・説明欄・固定コメント、X・リプライ、Threads 1つ目・2つ目)。書き方は過去の完成例の `投稿文.md` を参考に
  - ハッシュタグは5個まで
  - Xは日本語140文字相当まで
  - 本文にはどれも「検索ワード」を入れる
  - Threads は作者の独り言っぽく書く(本人の気持ちの部分は、あとで書き換えてもらうよう伝える)

## 5. 投稿セットを作る(道具)
```bash
python -m shorts.sticker_kit package <名前> [フォルダ名。省略すると正式名] --start <最初の投稿日を探し始める日> [--days 火木土月]
```
- 前のスタンプの投稿日程の後から始める(既存フォルダの `投稿文.md` や `投稿予約表.xlsx` を見る)
- 出てきた ⚠ はすべて直してから、もう一度実行する(投稿文だけ直すなら `--text-only`)

## 6. 仕上がりチェック(必ず目で見る)
`output/<名前>/*_frames.png` を Read で全部開いて確認する。
- [ ] 単語の途中で改行していない(「変／更です」など)。直すときは台本に `\n` を入れる
- [ ] 文字とスタンプが重なっていない、画面からはみ出していない
- [ ] 最後の画面に正しいスタンプ名と「『検索ワード』で検索」が出ている
- [ ] 長さの目安:トーク型 約20秒、テンポ型 約16秒、クイズ型 約8秒

直したら、もう一度 `package` を実行する。

## 7. 渡す
1. `git add` してコミット・push する。zip は .gitignore に `<フォルダ名>/*.zip` を追加して含めない
2. SendUserFile で、動画4本(display: render)と zip(display: attach)を送る
3. 返事で伝えること
   - 分析
   - 4本の構成と投稿日
   - 確認してほしいこと(正式名・検索ワード・除外した重複・販売している種類の数・URLの差し替え)
