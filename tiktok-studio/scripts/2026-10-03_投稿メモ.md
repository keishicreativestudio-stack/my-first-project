# 10/3（Day3）投稿メモ｜仕事が速い人のプロンプト5選

台本：`2026-10-03.json`
型：D（フォトモード）
投稿時間の目安：朝7時台（出勤前に保存してもらう）

撮影は不要です。画像を8枚書き出して、TikTokのフォトモードで投稿します。

```bash
cd tiktok-studio
python3 make_video.py scripts/2026-10-03.json --photos
```

→ `out/2026-10-03_photos/01.png 〜 08.png`

## 8枚の中身

| ページ | 内容 |
|---|---|
| 1 | コピペで使える 仕事が速い人のプロンプト5選 |
| 2 | ① メールを1分で書く |
| 3 | ② 会議メモを整理する |
| 4 | ③ 資料の骨組みを作る |

## 投稿のしかた
1. 8枚をスマホの写真アプリに保存する
2. TikTok で「＋」→「アップロード」→ 右上の「写真」を選び、01〜08 の順にタップする
3. 「写真」モードになっていることを確認する（「動画」にすると自動でスライドショーになり、ゆっくり読めない）
4. 音源は落ち着いた流行り曲を選ぶ（音量は低め）

## 投稿キャプション（どれか1つ）

1. 仕事が速い人がこっそり使ってるAIの頼み方5つ。保存して明日の仕事でそのまま使って。あなたが一番使いそうなのは何番？
2. コピペでOK。メール・議事録・資料作り…AIに任せていい仕事5選【Day3】
3. ChatGPTに「何を頼めばいいかわからない」人へ。まずはこの5つから。
