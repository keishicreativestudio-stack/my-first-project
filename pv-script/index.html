Tempo120 BPM
VOなし（文字で伝える）

前提：ブランドは「AIで映像・デザイン・LINEスタンプなどを作るクリエイティブスタジオ」と仮定しています。スタジオ名、作品、色は差し替え前提です。参考にした動画の映像や素材は使わず、構成と演出の考え方だけを取り入れています。

Aリサーチ：かっこいい映像は何をしているか

評価の高いプロモーション映像、タイトルバック、予告編、SNS広告の作り方を調べて、今回そのまま使える考え方を抜き出しました。

Apple / 製品フィルム

ゆっくり見せて、光で語る

製品は「ヒーローの登場 → 細部 → 使われる場面」の3部構成。登場は光の当たり方を変えながらゆっくり見せます。文字は1場面に短い1文だけで、動きは控えめです。

使う：途中に1回だけ、動きを止めて1文を見せる「間」を作る。

Nike “You Can't Stop Us” (2020, W+K)

形と動きが一致した瞬間につなぐ

画面を左右に割り、別々の選手の動きを鏡のようにつないだ90秒。4,000本の素材から36組の対をつくり、合成に1,000時間以上かけたと言われています。

使う：「入力した言葉」と「できあがった作品」を左右に並べ、形がそろった瞬間に切り替える。

Linear / 機能紹介フィルム

ナレーションなしで、1動作ずつ見せる

ナレーションも素材映像も使わず、実際の画面を1操作ずつ見せて20秒ほどで伝えます。見る人が「本物だ」と信じられることを優先しています。

使う：実際の入力画面（カーソルと打鍵）を映像の芯にする。作り物っぽいUIは出さない。

Se7en タイトルバック (1995, Kyle Cooper)

質感で世界観を決める

文字を手で引っかき、フィルムで撮影した、ほぼアナログな作り。文字のゆがみや揺れだけで作品の空気を伝え、以降のモーションデザインに大きな影響を与えました。

使う：デジタルでも薄いノイズやフィルムの粒子を乗せて、手触りを残す。

Spotify Wrapped

スマホ画面いっぱいの太字と、少ない色

高コントラストの限られた色の上に大きな太字を置き、文字は必ず平らな色面に乗せて読みやすくします。形式は毎年同じで、色と書体だけを変えています。

使う：縦画面で文字を大きく、1画面1メッセージ。色は黒・白・アクセント1色に絞る。

Nothing Phone (3) ティザー

1つの視覚言語を最後まで貫く

「光が言葉になる」という一文と、ドットの並び（ドットマトリクス）だけで新機能を予告しました。見せすぎず、1つの表現で印象を統一しています。

使う：全編を「点滅するカーソル」で貫く。最後は作品1つ1つをドットにしてロゴを組む。

Apple “Think Different” (1997)

宣言文の組み立て

「どんな人か」→「どう振る舞うか」→「だから世界を変える」と積み上げ、最後にロゴと2語だけ。白黒映像とナレーションだけで60秒を持たせました。

使う：テロップを「きっかけ → できること → 約束」の順で積み上げる。

映画予告編の構成

3幕で盛り上げて、最後に一撃

静かな導入 → 期待を積む中盤 → 音と絵が最も密な終盤、の波で作ります。上昇音のあとに一瞬の無音を入れてから衝撃音を入れ、最後は短い締め（ボタン）で終えます。

使う：0.1秒の無音 → 衝撃を2回だけ。締めはEnterキーの音で暗転。

SNS広告の最初の3秒

1.7秒で判断される

面白くなければ約1.7秒でスクロールされる、という調査があります。3秒後にも見続けている人の割合（フック率）はTikTokで40%以上、Metaで30%以上が良い目安とされます。音なしで見る人も多いので、最初の画面は文字で伝わる必要があります。

使う：0秒目から文字を打ち始める。ロゴから始めない。

今回採用する演出の原則

  1. ロゴから始めない。0秒目に「何が起きるか気になる」動きを置く。ロゴは最後に1回だけ。
  2. 音なしでも伝わる。すべての要点をテロップで出す。音は気持ちよさを足す役。
  3. 1画面1メッセージ。文字は大きく、平らな色面に乗せる。
  4. 形がそろった瞬間に切る。文字の曲線と作品の輪郭を重ねてつなぐ。
  5. 途中で1回止める。速いカットの後に、1文だけの静かな場面を置く。
  6. だんだん速く。終盤はカットの長さを1秒 → 0.5秒 → 0.25秒と縮める。
  7. 衝撃は2回まで。直前に0.1秒の無音を入れる。多すぎると効かない。
  8. 質感を1枚足す。薄いフィルムの粒子と周辺減光で、CGの平たさを消す。

Bコンセプト

Key line

打った言葉が、
そのまま作品になる。

このスタジオの価値は「思いついた言葉を、すぐに形にできる」こと。映像全体を、白い画面で点滅するカーソルから始めます。言葉を打つたびに、その言葉が作品に変わっていきます。ナレーションは使わず、打鍵とテロップだけで進めます。

貫く要素点滅するカーソル。全カットの始まりと終わりに必ず出す。
色黒・白と、アクセント1色（カーソルの色）。作品の色だけが例外。
書体太いゴシック1書体。数字と英字は等幅書体。
質感薄いフィルムの粒子、周辺減光、光のにじみ。

E制作メモ

用意してもらうもの

  • スタジオ名とロゴ（なければロゴも作ります）
  • 作品画像 12〜20枚（ポスター、キャラ、スタンプ、動画の1コマなど）
  • 最後に出す連絡先（アカウント名、DM、URL）
  • アクセントの色（決まっていなければ候補を出します）

作り方（前回と同じ仕組み）

  • 映像はブラウザのCanvasで1コマずつ描き、1080×1920・30fpsで書き出し
  • 音楽と効果音はプログラムで合成し、カットの時刻にぴったり合わせる
  • ページ上でコマ送りしながら調整し、決まったらMP4にする
  • 公開前チェック：音を消して見ても意味が伝わるか、3秒目で何が起きているか
