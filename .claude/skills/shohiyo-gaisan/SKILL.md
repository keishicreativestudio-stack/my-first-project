# 販売図面 → 資金計算書（諸費用概算）

生成スクリプト: `shohiyo/make_estimate.py`（仲介手数料は `shohiyo/reds_fee.py`＝REDS calc10_2 ロジック）

## 手順

1. **図面を読む**（PDF は pdf スキル、画像はそのまま Read）。次を拾う:

   | JSON キー | 図面での表記 | 備考 |
   |---|---|---|
   | `name` | 物件名・マンション名・号棟 | |
   | `address` | 所在地・住居表示 | |
   | `type` | 種別 | `新築戸建` / `中古戸建` / `新築マンション` / `中古マンション` / `土地` のどれか。「新築」「未入居」「建築中」→新築、築年月があり居住歴あり→中古 |
   | `price` | 価格 | **円**で。税込価格（新築は税込表示が普通） |
   | `deal` | 取引態様 | `仲介`（一般媒介・専任・専属専任・媒介）/ `売主` / `代理` |
   | `built_year` | 築年月の西暦年 | 1981年以前なら旧耐震注記が自動で付く |
   | `management_fee` / `repair_reserve` | 管理費・修繕積立金（月額） | マンションのみ |
   | `initial_repair_fund` | 修繕積立基金 | 新築マンションで記載があれば |

   読めなかった項目は推測で埋めず、省略する（既定値が入る）。価格・種別・取引態様が読めない場合はユーザーに確認する。

2. **ユーザー指定があれば反映**: `fee_plan`（`割引`=既定・REDS計算 / `無料` / `半額`）、`customer`（お客様名）、`staff`（担当）、
   `loan`（`amount` 融資額・既定は物件価格の全額、`rate` 金利%・既定0.945、`years` 既定35、`bonus` ボーナス加算額）、
   `overrides`（`登記費用` などを金額で上書き）。

3. **生成と再計算**:
   ```bash
   python3 shohiyo/make_estimate.py 物件.json 出力.xlsx
   python3 <xlsxスキル>/scripts/recalc.py 出力.xlsx 300   # LibreOffice。初回は数分かかる
   ```
   `status: success` かつ `total_errors: 0` を確認。

4. **ユーザーに送る**（SendUserFile）。返信には、読み取った物件情報・REDS仲介手数料と他社との差額・月々返済額・
   自動で置いた概算（登記・火災保険・固都税）を短く添える。図面と食い違いがないか確認を促す。

## 自動で決まる項目

- 契約書印紙代: 売買価格から（軽減税率、2027年3月31日まで）
- 仲介手数料: 取引態様が売主・代理なら0。仲介なら fee_plan に従う。他社側は法定上限（税込）
- 事務代行手数料: REDS 0円 / 他社 55,000円
- 融資事務手数料: 融資額×2.2%、金消契約印紙: 融資額から
- 表示登記（新築戸建のみ）15万円、管理費等清算金（マンション）= 月額×2ヶ月
- 登記費用・火災保険・固都税清算は目安額（`make_estimate.py` の estimate_* 関数）
