# my-first-project

## note 売れている有料記事リサーチ

毎日 午前1時ごろ（JST）に Claude の Routine が自動で起動し、note の有料記事を調査します。
有料記事は購入せず、公開されている情報だけで分析します。

- `scripts/note_research.py` … データ収集（人気ハッシュタグから有料記事を集め、詳細・作者情報を取得）
- `data/YYYY-MM-DD/articles.json` … その日の全有料記事の生データ
- `reports/YYYY-MM-DD.md` … 日次レポート（定量ランキング + Claude による定性分析）

### 調べている項目

| 項目 | 取得元 |
|---|---|
| テーマ・タイトル・ハッシュタグ | 記事詳細 API |
| 無料パート本文・見出し・文字数 | 記事詳細 API（購入前に誰でも読める部分） |
| 有料パートの文字数・画像数・添付ファイル数 | 記事詳細 API（`remained_*`） |
| 見出し画像 | 記事詳細 API（画像を取得して Claude が目視で分析） |
| 価格・スキ数・コメント数・購入者レビュー数 | 記事詳細 API |
| 作者のフォロー数・フォロワー数・記事数 | 記事詳細 API |
| スキの前日比（売れ行きの勢い） | 前日のスナップショットとの差分 |

購入数は note が公開していないため、「購入者レビュー数」「スキ」「コメント」「前日比の伸び」から売れ行きを推定しています（自己申告の販売部数は加点しません）。

**重点: 販売部数や収益などの「実績」を書いていないのに、フォロワーが少なくても売れている記事** を中心に深掘りします（既定はフォロワー1,000人以下）。
タイトル・無料パート・作者プロフィールのどこかに「〇部突破」「完売」「月〇万円」「収益〇円」「フォロワー〇人達成」「0→1」などがある記事は「実績アピールあり」として参考扱いにしています。

手動実行: `python3 scripts/note_research.py --pages 3 --top 30 --max-followers 1000`
