# LINEスタンプ広告ショート動画 ― リサーチ・分析・企画

## 1. リサーチでわかったこと

### 人はなぜスタンプを買うのか
- **気持ちを代わりに言ってくれる**: 言葉にしにくい気持ちを伝えられるスタンプや、「あるある」と思えるスタンプは共感されやすく、よく使われます[^coconala]
- **毎日使える**: 「おはよう」「ありがとう」「了解」など、日常会話でよく使う言葉が入ったスタンプは実用的です[^coconala]
- **理由はシンプル**: 「絵がかわいい・キャラが好き」「文字で返すよりスタンプの方が早い」「相手に親しみやすい印象を与えられる」[^survey]
- **小さな出費**: スタンプ利用者の76.8%が有料スタンプを買ったことがあり、10〜20代の支出は「500円未満」が最多です[^survey]。つまり**衝動買いされやすい価格帯**です

### どうやって売れるのか
- **使っている場面を見せる**: トーク画面でスタンプを使っている様子を見せると、自分が使う場面を想像しやすくなります[^unicorn]
- **拡散はTikTokが強い**: TikTokは興味外のユーザーにもおすすめ表示されるので、Instagramより拡散力が高いと言われています。Instagramは個人アカウントだと投稿からリンクへ飛べないため、売上につながりにくいという声があります[^unicorn]
- **初動が大事**: 発売直後に一定の売上が出ると「新着」の上位に載り続け、そこからさらに売れる連鎖が起きることがあります[^coconala]
- **曜日**: 火曜・木曜がよく売れる傾向があると言われています(公式スタンプの新作が出る曜日)[^coconala]
- **検索とリンク**: TikTokのプロフィールにリンクを置く方法と、ショップでの検索ワードを伝える方法の両方が使われています[^link]

### ショート動画広告の鉄則
- **最初の2秒**: 離脱の約8割は最初の2秒で起きます。冒頭で悩みや常識外れの事実を言い切ります[^hook]
- **2秒ルール**: 2秒以上同じ画面を続けず、テンポを保ちます[^hook]
- **重視される指標**: 2025年以降は、視聴維持率・もう一度見られる率(リワッチ率)・コメント率が特に重要とされています[^hook]
- **長さ**: 使っている場面を15〜30秒でまとめた動画は、広告費をかけなくてもおすすめに載る可能性があります[^product]

### 守るべきルール(LINEのガイドライン)
- **トーク画面の再現**: 広告でLINEのトーク画面を見せるときは、実機のスクリーンショットを使うか、それと同じくらい忠実に再現する必要があります[^guideline]
- **トーク画面風のデザイン**: LINEのトーク画面を参考にした吹き出しを作るときは、**LINEと違うデザイン・色**にする必要があります[^guideline2]
- **ロゴ**: LINEのロゴを変形したり、アニメーションを付けたりしてはいけません[^guideline2]

→ この動画のトーク画面は、**ピンク系の配色・しっぽのない角丸の吹き出し・LINEロゴなし**のオリジナルデザインにしています。

## 2. 分析:買ってもらうまでの流れ

```
止まる(2秒) → 自分ごとになる → 欲しくなる → 背中を押される → 買い方がわかる
  フック         あるある場面        種類の多さ        「どこの？」         検索ワード
```

スタンプは安いので、「欲しい」と思った瞬間に**買い方がすぐわかれば**そのまま買ってもらえます。
そのため、どの型も最後は**「LINEスタンプショップで「○○」で検索」**を大きく出して締めます。

## 3. 3つの型(A/Bテスト用)

| 型 | 長さ | 狙う指標 | 構成 |
|---|---|---|---|
| **A トーク型** `s01_chat` | 約20秒 | 購入(自分が使う場面を想像させる) | フック → あるある会話3つ → **「そのスタンプどこの？」と聞かれる** → 全種類一覧 → 検索ワード |
| **B テンポ型** `s02_tempo` | 約16秒 | 視聴維持率・保存 | フック → 「○○な時に」+スタンプを**BGMの2拍ごと**に切り替え(8種) → 一覧 → 検索ワード |
| **C クイズ型** `s03_quiz` | 約8秒 | コメント・リワッチ | 「今日の気分どれ？」→ 4択 → 「コメントで番号」→ 検索ワード(短いのでループ再生されやすい) |

### 演出のこだわり
- **スタンプの動き**: 登場時は「ぽよん」と跳ねて、その後もぷるぷる・ぷかぷか動き続けます(静止画スタンプでも生きているように見えます)
- **集中線**: スタンプの後ろで放射状の光が回り、スタンプに目が行きます
- **効果音**: メッセージ受信の「ピコッ」はオリジナル音です(LINEの通知音は使っていません)
- **安全エリア**: 文字とスタンプは、TikTok/リールのボタンや投稿文と重ならない範囲に置いています
- **初動の話題作り**: A型の「どこの？」は、友だちに聞かれる=みんな欲しがる、という**社会的証明**の演出です

## 4. 投稿・運用プラン

1. **発売日〜3日間に集中投稿**(初動で新着の上位に入るため)
   - 1日目 A型、2日目 B型、3日目 C型
   - 火曜か木曜の発売・投稿がおすすめです
2. **3本の結果を比べる**(投稿から48時間後)
   - 視聴維持率が一番高い型 → 冒頭のフックを変えた版を作る
   - コメントが多い型 → 返信動画(コメントに返信する形の動画)で2本目を作る
3. **TikTokを主にする**: Instagramはリールとストーリーズのリンクスタンプを併用します
4. **プロフィール**: TikTokのプロフィールにスタンプショップの作者ページURLを置きます
5. **フックを量産する**: 同じ構成でフックの言葉だけ変えて、何本も作ります(`hook:` を1行変えるだけです)

### フックの候補(テストするもの)
- 「文字打つより スタンプ1個の方が 伝わる時ある」(共感)
- 「既読スルーしたくない時 これ送っとけばOK」(悩み解決)
- 「このスタンプ送ったら 返信が3倍になった」(効果の誇張は避けて、実体験ベースで)
- 「○○な人にしか 刺さらないスタンプ作った」(ターゲット指名)
- 「今日の気分 どれ？」(参加型)

## 5. 実物のスタンプで作るときに必要なもの

- **スタンプ画像(PNG)**: 全種類分。LINE Creators Market に提出した画像で大丈夫です
- **スタンプの名前(タイトル)**
- **ショップでの検索ワード**(スタンプ名そのままでOK)
- (わかれば)どんな人向けか、何種類セットか

画像を見て、キャラの雰囲気とセリフに合わせて**会話の場面・フック・色合いを作り直します**。
