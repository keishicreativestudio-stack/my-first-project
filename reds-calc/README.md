# 仲介手数料計算（消費税10％）の再現

https://www.reds.co.jp/calc10_2/ の計算ロジック（`page-calc-common.js` の `calc_brokerage_fee`）を再現したものです。
元のコードと 60万円〜3億円（0.1万円刻み × 購入/売却 × 上限あり/なし、約131万パターン）で照合し、全項目が一致することを確認済みです。

- `calc.js` … 計算ロジック（ブラウザ / Node.js 両対応）
- `index.html` … 計算画面（ブラウザで開くだけで動きます）
- `test/calc.test.js` … テスト（`node --test reds-calc/test/calc.test.js`）

## 入力

| 項目 | 内容 |
|---|---|
| 査定種別 | 購入 / 売却 |
| 物件価格 | 万円単位。数字以外はエラー、60万円未満もエラー |
| 上限設定 | あり / なし。**売却かつ1億円以上**のときだけ表示 |

## 計算ロジック

消費税は 1.1 倍。端数は特記なければ **切り捨て**。

### 1. 法定上限（税抜）

| 物件価格 | 式 |
|---|---|
| 200万円以下 | 価格 × 5% |
| 400万円以下 | 10万円 ＋ (価格 − 200万円) × 4% |
| 400万円超 | 価格 × 3% ＋ 6万円 |

法定上限（税込）＝ 法定上限（税抜）× 1.1

### 2. REDS手数料（税抜）

| 物件価格 | 税抜手数料 | 税込上限額 |
|---|---|---|
| 200万円以下 | 価格 × 5% − 3万円 | なし |
| 200万円超〜400万円以下 | 価格 × 4% − 1万円 | なし |
| 400万円超〜1,000万円未満 | 法定上限（税抜）− 3万円 | 329,990円 |
| 1,000万〜1,250万円未満 | 価格 × 2.7% ＋ 3万円 | 393,930円 |
| 1,250万〜1,500万円未満 | 価格 × 2.625% ＋ 3万円 | 453,740円 |
| 1,500万〜1,750万円未満 | 価格 × 2.55% ＋ 3万円 | 509,430円 |
| 1,750万〜2,000万円未満 | 価格 × 2.475% ＋ 3万円 | 560,990円 |
| 2,000万〜2,250万円未満 | 価格 × 2.4% ＋ 3万円 | 608,430円 |
| 2,250万〜2,500万円未満 | 価格 × 2.325% ＋ 3万円 | 651,740円 |
| 2,500万〜2,750万円未満 | 価格 × 2.25% ＋ 3万円 | 690,930円 |
| 2,750万〜3,000万円未満 | 価格 × 2.175% ＋ 3万円 | 725,990円 |
| 3,000万〜3,250万円未満 | 価格 × 2.1% ＋ 3万円 | 756,930円 |
| 3,250万〜3,500万円未満 | 価格 × 2.025% ＋ 3万円 | 783,740円 |
| 3,500万〜3,750万円未満 | 価格 × 1.95% ＋ 3万円 | 806,430円 |
| 3,750万〜4,000万円未満 | 価格 × 1.875% ＋ 3万円 | 824,990円 |
| 4,000万〜4,250万円未満 | 価格 × 1.8% ＋ 3万円 | 839,430円 |
| 4,250万〜4,500万円未満 | 価格 × 1.725% ＋ 3万円 | 849,740円 |
| 4,500万〜4,750万円未満 | 価格 × 1.65% ＋ 3万円 | 855,930円 |
| 4,750万〜5,000万円未満 | 価格 × 1.575% ＋ 3万円 | 857,990円 |
| 5,000万円以上 | 価格 × 1.5% ＋ 3万円 | なし（※） |

※ **売却・1億円超・上限設定あり** の場合は税込 1,683,000円 固定（税抜 = 1,683,000 ÷ 1.1 を切り上げ = 1,530,000円）。
1億円の 1.5%＋3万円＋消費税 と同額なので、1億円を超えても手数料が増えない仕組みです。

税込手数料 ＝ 税抜 × 1.1（切り捨て）。これが税込上限額を超えた場合は:

- 税込手数料 ＝ 上限額
- 税抜手数料 ＝ 上限額 ÷ 1.1（**切り上げ**）
- 表示料率 ＝ (税抜手数料 − 3万円) ÷ 価格 × 100（小数3桁で切り捨て）、表示は「約(料率%＋3万円)×1.1」

### 3. その他の出力

- 税額 ＝ 税込手数料 − 税抜手数料
- 差額 ＝ 法定上限（税込）− 税込手数料
- 割引率 ＝ 差額 ÷ 法定上限（税込）× 100（小数1桁で切り捨て）

## 元ページの仕様上のクセ（そのまま再現）

- 400万円以下は実際の式が「5% − 3万円」「4% − 1万円」でも、料率表示は「(3%＋3万円)×1.1」になる。
- 60万円ちょうどだと手数料は 0円。
- 上限設定は1億円「以上」で表示されるが、固定額が効くのは1億円「超」（1億円ちょうどでは結果は同じ）。
