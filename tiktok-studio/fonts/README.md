# フォント置き場

ここに `.ttf` / `.otf` / `.ttc` を置くと、そのフォントが優先して使われます。

テロップ向けのおすすめ（どれも無料・商用利用可）:
- **Noto Sans JP**（Black / ExtraBold）… https://fonts.google.com/noto/specimen/Noto+Sans+JP
- **M PLUS Rounded 1c**（ExtraBold）… 丸くてやわらかい印象
- **Dela Gothic One** … 太くてインパクト重視（フック向け）

置かない場合は、Mac はヒラギノ、Windows は游ゴシック/メイリオを自動で探します。
