# 間取りメーカー

四角を組み合わせて間取りの形を作るブラウザアプリです。
`index.html` をブラウザで開くだけで動きます（インストール不要）。

## できること

- 「324×465」のように **幅×奥行（mm）を1mm単位で入力** して四角を追加
  - `324×465` / `324x465` / `324*465` / `324 465` / 全角数字にも対応
  - 四角を選んだ状態で追加すると、その右隣にぴったり並ぶ
  - 最近使ったサイズはワンクリックで再追加
- 選んだ四角のサイズ（幅×奥行）と位置（X・Y）を1mm単位で変更
- ドラッグで移動、四隅・各辺のハンドルで伸縮
- **辺に吸着**：四角どうしの辺・中心が近づくと赤いガイドが出て、ぴったり合わさる
- ドラッグ時の吸着間隔（1 / 10 / 100 / 455 / 910mm）、矢印キーで1mm移動（Shiftで10mm）
- 四角ごとの面積と、全体の合計面積（㎡・帖・坪、重なりは二重に数えない）
- 縦横入替（R）、右隣に複製（Ctrl+D）、削除（Del）、元に戻す／やり直し
- ブラウザに自動保存、JSONで保存・読込、PNG画像で書き出し
- スマホ対応（ピンチで拡大縮小）

帖数は 1帖 = 1.62㎡ で換算しています。
