## 用意するもの（2つ）

撮ったものは `tiktok-studio/scripts/rec/` に、次の名前で保存します。

| ファイル名 | 内容 | ポイント |
|---|---|---|
| `1002_fridge.png` | ChatGPTで作った冷蔵庫のイラスト | 下の文で作る。写真のように見えない、イラストだと分かる絵にする |
| `1002_chatgpt.mp4` | スマホの画面録画 | イラストを作るところから、献立と買い物リストが全部出るまで |

### 冷蔵庫のイラストを作る文（ChatGPTに送る）

```
冷蔵庫の扉を開けて、正面から見た中身のイラストを作って。
・フラットで明るいイラスト調（写真のようにはしない）
・中身：卵、牛乳、キャベツ半分、にんじん、豚こま肉のパック、豆腐、納豆、ケチャップ、残りご飯のタッパー
・食材がはっきり見分けられるように、少し余白をとって並べる
・縦長の画像で
```

できた画像を長押しして保存し、`1002_fridge.png` として送ってください。
**献立は、このイラストを同じ会話でそのまま使って出してもらいます**（動画に出す画像と、AIに見せた画像を同じにするため）。

録画は**スマホで撮るのがおすすめ**です。縦長なので、動画の画面にそのまま大きく入ります。
iPhone はコントロールセンターの「画面収録」、Android はクイック設定の「スクリーンレコード」で撮れます。

### 献立を出してもらう文（イラストができた同じ会話で送る）

```
この冷蔵庫の中身で、3日分の夕飯の献立を考えて。
・2人分、1食30分以内
・今ある食材をできるだけ使い切る
・足りない食材は買い物リストにまとめて
```

### 撮影のコツ
- 送信する前から録画を始め、答えが出たら**ゆっくりスクロール**する（速いと読めない）
- 通知はオフにする（おやすみモードにすると確実）
- AIが食材を読み間違えることがあります。間違いが目立つ場合は撮り直すか、「一部読み間違いあり」とテロップで正直に出すと、かえってコメントが付きやすくなります
- 冷蔵庫がイラストであることは、動画のテロップ（イラストで再現）とキャプションの両方に入れる。もし写真のようにリアルな絵になったら、TikTokの「AI生成コンテンツ」ラベルも付ける

## 動画を作る

録画を送ってもらえれば、Day1と同じように、献立が出る場面と買い物リストの場面を切り出して仕上げます。
自分で作る場合：

```bash
cd tiktok-studio
python3 make_video.py scripts/2026-10-02.json
```

買い物リストが出る秒数に合わせて、台本の5つ目のシーンの `clip_start` を変えてください。
