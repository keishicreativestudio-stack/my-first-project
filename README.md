# ChatGPTプロンプト活用ショート動画（AIチャレンジ365 Day4）

TikTok / YouTube Shorts向けの縦型ショート動画を、HTML / CSS / JavaScriptのみ（外部ライブラリ・外部素材なし）で制作したものです。ブラウザで `index.html` を開くだけで、最初から最後まで自動再生され、終了後はシームレスにループします。

## 動画の目的

「ChatGPTに普通に質問するのをやめて、回答前に不足情報を質問させる一文を足す」というテクニックを、ChatGPT初心者やAIを仕事・副業に活かしたい層に向けて分かりやすく紹介する動画です。視聴者が動画を保存し、その場でChatGPTに試したくなることをゴールにしています。

## 再生方法

1. このフォルダ（`index.html` と同じ階層）をローカルサーバーで開く、またはブラウザで `index.html` を直接開きます。
   - 例: `python3 -m http.server 8000` を実行し、`http://localhost:8000/index.html` にアクセス。
   - ローカルファイルを直接ダブルクリックで開いても動作します。
2. ページを開くと同時に映像の自動再生が始まります（クリックや操作は不要）。
3. **音声（効果音・ナレーション）はブラウザの自動再生ポリシーにより、ページを開いただけでは鳴りません。** 画面上部に出る「🔊 クリックして音声ON」を1回クリック（スマホはタップ）すると、音声を有効化した状態で頭から再生し直されます。**録画する前に必ず一度クリックしてください。**
4. 動画は約29.5秒でループします（CTA表示後、シームレスに冒頭へ戻ります）。
5. `?debug=1` をURLに付けて開くと、左上に経過時間と現在のシーン名を表示するデバッグ表示が出ます（本番の見た目には影響しません）。
6. 音声有効化後は、画面をクリックする、または `R` キーを押すといつでも最初から再生し直せます（確認用）。

## 動画仕様

- 解像度: 1080 × 1920（9:16 縦型）
- 長さ: 約29.5秒（ループ再生）
- 使用技術: HTML / CSS / JavaScriptのみ（外部フォント・画像・ライブラリ不使用、システムフォントとインラインSVGのみ使用）
- セーフエリア: 上下左右に余白を確保し、TikTok / Shorts等のUI（いいねボタン、キャプション等）と重ならない設計
- 音声: 効果音はWeb Audio APIでその場合成（外部音源ファイル不使用）、ナレーションはブラウザ標準のWeb Speech API（`speechSynthesis`）による音声合成

### 音声について（重要）

- ナレーションの声質・有無は**再生する端末のOS/ブラウザが持っている日本語音声合成エンジンに依存**します。Windows / macOS / iOS / Android の主要ブラウザ（Chrome, Safari, Edge等）は標準で日本語音声を内蔵しているため、通常はそのまま自然な音声が再生されます。
- 万が一お使いの環境に日本語音声が見つからない場合、ナレーションは自動的に鳴らないだけで、エラーにはならず映像・字幕（画面上のテロップ）はそのまま正常に再生されます。
- より高品質な声にしたい場合は、いったんこの自動ナレーションをオフの状態で録画し（`audio.js` の `narrate` 呼び出し部分をコメントアウト、または後述の `VideoAudio.setEnabled(false)` を使用）、動画編集ソフト側でプロのナレーション音声や外部の高品質TTS（VOICEVOX等）を別トラックとして重ねる方法もおすすめです。
- 効果音だけを止めたい／ナレーションだけを止めたい場合は、ブラウザのコンソールで `VideoAudio.setEnabled(false)` を実行すると全音声を停止できます。

## 録画方法（動画ファイル化する場合）

ブラウザ上でアニメーションとして完結しているため、実際に `.mp4` 等のファイルに書き出す場合は画面録画を行います。

### 方法A: OS標準の画面録画（音声つきでおすすめ）

1. ブラウザを1080×1920相当の比率で表示（ウィンドウを縦長にする、またはブラウザの端末エミュレーション機能でカスタムサイズ 1080×1920 を指定）。
2. ページを開き、まず1回クリックして「🔊 クリックして音声ON」を消す（これで音声が有効化され、頭から再生し直される）。
3. **画面収録は「システム音声を含める」設定にしてから開始**してください（macOSの画面収録は音声収録オプションをオン、Windowsのゲームバー録画は既定でPC音声を含みます）。
4. 録画を開始 → ブラウザ側で `R` キーを押すか画面をクリックして頭出しする → CTA表示が終わるところ（約29.5秒後）で録画停止。

音声を含めない場合（方法Bなど画面のみのキャプチャ）は、書き出し後に動画編集ソフトでナレーション・BGMを別途乗せてください。

### 方法B: Playwright等での自動録画（開発者向け・映像のみ）

Chromiumの `recordVideo` オプションは映像のみを記録し、音声は含まれません。`1080x1920` のビューポートでページを開き、クリックで音声を有効化してから29.5秒待機して閉じることで、ノーカットの `.webm`（映像のみ）を自動生成できます。書き出し後、必要に応じて`ffmpeg`で `.mp4` に変換してください。

```bash
ffmpeg -i output.webm -c:v libx264 -pix_fmt yuv420p output.mp4
```

音声トラックも自動収録したい場合は、Xvfb + PulseAudio仮想デバイス + ffmpegのx11grab/pulse入力を組み合わせた収録環境を別途構築する必要があります（このリポジトリには含まれません）。
