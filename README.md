# 住まいコンシェルジュAI(V1)

AIが住宅購入の条件(エリア・予算・広さ・間取りなど)を一緒に整理する診断Webアプリ。
物件検索サイトのように条件をユーザー自身が決めるのではなく、暮らし方・将来設計を質問形式で聞き取り、
「あなたなら、このエリアで、このくらいの価格・広さの物件を探すと良い」まで提案する。

対象エリアは東京都・神奈川県・埼玉県・千葉県(1都3県)。

## 起動方法

```bash
npm install
npm run dev
```

`http://localhost:3000` を開く。スマートフォン幅での確認を推奨(Chrome DevToolsのデバイスモード等)。

主要ページ:

- `/` トップページ
- `/diagnose` 診断(1画面1質問、条件分岐あり)
- `/result` 診断結果(予算・おすすめエリア・物件条件・3プラン比較)
- `/contact` 問い合わせフォーム(モック送信)
- `/admin` 問い合わせ一覧(営業担当向け簡易ビュー)

## 技術構成

- Next.js 16 (App Router) / React 19 / TypeScript
- Tailwind CSS v4
- zustand (診断回答のstate管理・localStorage永続化)
- zod (入力バリデーション)

追加ライブラリは上記のみ。診断ロジック(`src/lib/logic/`)とUI(`src/app/`, `src/components/`)を分離しており、
将来的にLLM APIや外部データに差し替えやすい構成にしている。

## 診断ロジックの構成

`src/lib/logic/diagnosis.ts` がオーケストレーター。以下はすべてルールベースの決定論的な計算で、
LLM APIが未設定でも動作する(V1はこれ単体で完結)。

| モジュール | 役割 |
| --- | --- |
| `budget.ts` | 世帯年収・自己資金・既存借入から購入予算を計算 |
| `scoring.ts` | 50エリア(`src/data/areas.ts`)に対するスコアリング。ユーザー回答に応じて重み(通勤/予算/街の好み/子育て/住宅タイプ/資産性/車)を動的調整し、Must条件に大きく反するエリアは順位を下げる |
| `propertyCondition.ts` | 家族構成・予算・エリア相場から広さ・間取り・駅徒歩・築年数の推奨条件を算出 |
| `relaxation.ts` | 条件緩和の提案(Must条件を変える場合は「もしここだけ緩められるなら」として区別) |
| `plans.ts` | バランス/通勤重視/広さ重視の3プランを生成 |
| `buyerProfile.ts` | 回答傾向から購入者タイプの見出し・説明文を生成 |

## モックデータになっている部分(実データ化が必要)

- **エリアスコア・価格帯** (`src/data/areas.ts`): 50エリア分のスコア(静かさ・都会度・子育てのしやすさ等)と価格帯は
  V1用の仮データ。統計データに基づく実測値ではない。`isMockData: true` で明示している。
- **通勤時間** (`src/data/areas.ts` の `terminalAccessMinutes`): 実際の鉄道経路検索ではなく、路線ゾーンごとの目安時間から算出。
  ユーザーが入力した駅が主要ターミナル駅(東京・新宿・渋谷・池袋・品川・上野・横浜・大宮・千葉)と一致しない場合は、
  そのエリアの最短ターミナル時間+15分という粗い推定値にフォールバックする。
- **問い合わせデータの保存先** (`src/lib/server/submissionsStore.ts`): `.data/submissions.json` に保存するファイルベースの簡易実装。
  本番運用ではDB(CRM連携を見据えたテーブル)に置き換える前提。
- **問い合わせの送信先**: 実際の営業システム/メール送信/CRM連携は未実装。API (`/api/contact`) はモック保存のみ行う。

## 実データ化のために必要なもの(Phase 2)

- 実際の駅・路線マスタと経路検索API(乗換案内API等)
- エリアの相場・statistics(不動産流通機構のデータ等)、学校区・ハザードマップ等の周辺環境データ
- 実際の販売物件データ(物件検索APIやMLS的なデータ連携)
- CRM連携(問い合わせデータの永続化・営業フロー連携)
- メール送信(問い合わせ完了通知・営業への通知)
- LLM APIによる、より高度な提案文生成(現状はテンプレートベースの説明文)

## 重要な表現上の注意(実装済み)

- 住宅ローンの借入可能額・毎月返済額は「参考目安」であり、正式な融資審査結果ではない旨を結果画面に明記。
- 資産性については「必ず値上がりする」等の断定表現を避け、「参考評価」「売却しやすさを考慮」等の表現にとどめている。
- エリアスコアは公的統計等の裏付けがある実データではない旨を結果画面に明記している。
