# ショート動画 企画書「家を買う前の30秒」

## コンセプト
**現役の不動産営業が、家を買う前に知っておくべきことを30秒で教えるチャンネル。**
TikTok、Instagram リール、YouTube ショートに同じ動画を投稿します。

この企画にした理由:
- **普段の仕事がそのままネタになる**。SUUMO入稿、販売図面、諸費用の説明、内見対応など、日々の業務で話している内容を動画にするだけです
- **顔出しなしで続けられる**。写真と文字と効果音だけで構成するので、撮影は要りません。台本を書いて1コマンドで書き出せます
- **集客につながる**。豆知識で信頼を積み上げ、物件クイズで問い合わせにつなげます

## 2つの型を交互に投稿する

| 型 | 中身 | 狙い | 目安の長さ |
|---|---|---|---|
| **豆知識(tips)** | フック → ポイント3つ → 結論 → 保存・フォロー誘導 | **保存数**とフォロワーを増やす | 25〜35秒 |
| **この家いくら？(property)** | 写真 → 物件データ → 「正解は…」 → 価格発表 → 詳細はプロフへ | **コメント数**と問い合わせを増やす | 20〜30秒 |

推奨ペースは **1日1本(豆知識4 : 物件3 / 週)** です。最初の30本までは毎日投稿を目標にします。

### 伸ばすための仕組み(ツールに組み込み済み)
- **最初の1秒のフック**: 大きな文字で「損する」「知らないと」「いくら？」のような言葉を出します
- **進捗バー**: 画面上部のバーで残り時間が見えるので、最後まで見られやすくなります(視聴維持率が上がる)
- **ポンッという効果音と文字のポップ**: テンポを出して、途中で離脱されにくくします
- **保存の誘導**: 豆知識は「保存して見返してね」で締めます。保存数はおすすめ表示に強く効きます
- **コメントの誘導**: クイズ形式なので「予想は当たった？」にコメントが付きやすくなります
- **統一デザイン**: ネイビーと黄色、方眼(間取り図モチーフ)、シリーズ名と話数で、一目で「あのアカウント」とわかるようにします

## 投稿の運用ルール
1. **週1回まとめて作る**: 台本7本をまとめて書き、`python -m shorts scripts/` で一括で書き出します
2. **投稿文**: `output/*.txt` に投稿文とハッシュタグが出るので、コピペして使います
3. **音源**: TikTok とリールはアプリ内の流行音源を小さめの音量で付けると伸びやすいです(その場合は `--no-bgm` で書き出し)
4. **振り返り**: 週1回、**保存率・視聴維持率・コメント数**を見ます。伸びたフックの言い回しは他のネタでも使い回します
5. **伸びたネタは続編にする**: 「○○ 第2弾」でシリーズ化します

## 物件動画の注意(必ず確認してください)
- 物件動画も**不動産広告**です。不動産の表示に関する公正競争規約に沿って作ってください(取引態様、会社名、免許番号などの表示)。表示内容は `brand.yaml` と台本の `deal_type` で設定できます
- **成約済み・販売していない物件は投稿しない**でください(おとり広告)。成約したら動画を非公開にします
- **写真の使用許可**(売主・元付業者)と、**写り込み**(表札、人、隣家、車のナンバー)を確認してください
- 価格表記は税込総額にしてください
- 豆知識の数字や制度は、投稿前に最新の内容か確認してください(税制や金利は変わります)

## 台本を Claude に作らせるときのプロンプト例
```
docs/企画書.md のネタ帳 #11「『南向き』でも日当たりが悪い家の特徴」を、
scripts/tips/001_shohiyo.yaml と同じ形式の YAML 台本にして scripts/tips/011_*.yaml に保存して。
フックは15文字前後×3行以内、ポイントは3つ、本文は1行14文字以内で改行を入れて。
```
